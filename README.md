# Бақайдгирӣ-Даъватнома

Системаи **комилан офлайн** барои бақайдгирии хонандагон, сохтани даъватнома ва варақаи имтиҳонсупорӣ, ва воридкунии дастии натиҷаҳо.

> Ин лоиҳаи **мустақил** аст. Ба репозиторияи Geografia ва сервери Render ҳеҷ тағйир дода намешавад — танҳо UI/идея илҳом гирифта шудааст.

## Хусусиятҳо

1. **Бақайдгирӣ** — 13 майдон + сурат (камера / файл) → ID-и дарози рақамӣ
2. **Варақаи 1 — Даъватнома** (A4, чоп / PDF) бо логотипҳо ва ҷадвали пурра
3. **Варақаи 2 — Варақаи имтиҳонсупорӣ** — сарварақи кӯтоҳ (ID, фан, синф, олимпиада) + поёни холӣ барои чопи саволҳо
4. **Натиҷаҳо** — холро дастӣ ворид кунед, филтр, Export `.xlsx` (Student ID ҳамчун матн)
5. **SQLite** + суратҳо дар `data/` — пас аз restart маълумот боқӣ мемонад

## Насб (offline)

```bash
# 1. Zip-ро кушоед ё clone кунед
cd Baqaydgiri-Davotnoma

# 2. Virtualenv
python3 -m venv .venv

# Linux / macOS:
source .venv/bin/activate

# Windows:
# .venv\Scripts\activate

# 3. Бастаҳо
pip install -r requirements.txt

# 4. Танзимот
cp .env.example .env
# .env-ро кушоед ва ADMIN_PASS / SECRET_KEY-ро иваз кунед

# 5. Оғоз
python server.py
```

Браузер: **http://127.0.0.1:5000**

Логин: `admin` / парол аз `.env` (пешфарз `admin123`)

## Раванди кор

1. Админ → Бақайдгирӣ → 13 майдон + сурат → **Бақайдгирӣ + Сохтани ID**
2. **Захираи варақаҳо (1+2)** → файлҳо ба `data/exports/` + кушодани чоп
3. Ба хонанда варақаи тест (қоғаз) дода мешавад
4. Пас аз имтиҳон → ҷадвали **Натиҷаҳо** → холро дастӣ нависед
5. Филтр + **Export .xlsx**

## Камера

Камера танҳо дар **localhost** ё HTTPS кор мекунад. `http://127.0.0.1:5000` — OK.

Рӯйхати камераҳо дар dropdown намоиш дода мешавад.

## Export .xlsx

Сутунҳо: Ном | Student ID (матн) | Мактаб | Синф | Ҷинс | Фан | Олимпиада | Хол | Макс | Фоиз | Статус | Санаи бақайд | Санаи хол

Student ID ҳеҷ гоҳ scientific notation намешавад.
